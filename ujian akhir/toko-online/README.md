# Ruang Tekno

Proyek toko online sederhana untuk ujian praktik. Desainnya mengikuti palet krem dan emas serta tipografi serif pada proyek referensi.

## Menjalankan

Buka `index.html` di browser atau gunakan ekstensi Live Server di Visual Studio Code. Halaman terdiri dari beranda, katalog produk, dan formulir kontak. Contoh materi JavaScript Bab 1–15 ditampilkan di Console browser melalui `app.js`.

Sebelum mengumpulkan tugas, sesuaikan `author` pada meta tag dan tanggal lahir contoh di `app.js` dengan data pribadi.
